# wcag-auditor

ML-assisted WCAG 2.2 auditor for web UI screenshots. The Python library in `packages/auditor` is the product and the thesis artefact; everything else wraps it. Read `PLAN.md` before any milestone; the milestone prompt tells you which sections. Milestone prompts are in `MILESTONES.md`; UI spec in `DESIGN_SPEC.md`; criterion table in `CHECK_CATALOGUE.md`.

## Layout
- `packages/auditor`  pure Python lib + CLI `auditor` (capture / rules / elements / modules / fusion / report / eval / detector)
- `services/app`      FastAPI + SQLite + in-process job runner (runs `auditor` in a subprocess)
- `apps/web`          Next.js 16 (App Router), shadcn/ui on Base UI, Tailwind v4, TanStack
- `fixtures/`         small copies of benchmark captures + golden outputs (committed)
- `data/`             runs, models, app.db (gitignored). `BENCHMARK_DIR` points at the frozen benchmark (read-only)

## Never modify
- Anything under `$BENCHMARK_DIR` or `../04_Data_Collection/` (frozen benchmark, ground truth, `vendor/axe.min.js`).
- `fixtures/**/golden/*` unless the task says "regenerate goldens" and you show the diff in your report.
- Threshold values in `packages/auditor/auditor/protocol.yaml`. Never hard-code 4.5, 3.0, 24, 1.5, 2px, 0.3 in code; a test greps for them.
- `apps/web/src/api/types.ts` (generated by `pnpm gen:types`).

## Commands
- `make check`      ruff + mypy + pytest (no browser) + biome + vitest
- `make smoke`      `auditor run --folder fixtures/synth/sc1-4-3/<folder>` → report.json; `curl /health`; `pnpm build`
- `uv run pytest packages/auditor -q`            fast unit + golden tests
- `uv run pytest packages/auditor -m browser`    needs `uv run playwright install chromium`
- `uv run pytest services/app -q`
- `pnpm -C apps/web test` | `pnpm -C apps/web e2e` | `pnpm -C apps/web lint`
- `make eval`       `auditor eval --benchmark $BENCHMARK_DIR --truth $TRUTH_PATH --out eval/$(date +%F)`
- `make goldens`    regenerate goldens (only when a prompt says so)

## Conventions
- Python 3.12, fully typed. `auditor/schema.py` (Pydantic v2) is the only finding/capture shape.
- Modules: one file per SC, `modules/sc_1_4_3.py`, `def run(ctx: ModuleContext) -> list[Finding]`, pure, no I/O.
- Focus SCs (2.4.7, 2.4.11, 2.4.12, 2.4.13) are keyed by `focus_index`, never matched by bbox. Ground truth: `focus_judgments[].{v247,obs,v2413}`.
- Page SCs (1.4.3, 1.4.11, 2.5.7, 2.5.8) are boxes in document CSS px; match at IoU ≥ 0.3 (value from protocol.yaml).
- All coordinates go through `frames.py`. Focus PNGs are viewport images scaled by `png_scale`; full-page screenshot is 1 px = 1 CSS px.
- Capture folder layout is fixed by `capture_and_select.py` v2.4.0 (see `fixtures/README.md`).
- axe-core 4.13.0 vendored at `auditor/rules/vendor/axe.min.js`; a test asserts its sha256 equals the benchmark copy.
- Playwright 1.63.0 / Chromium 153 pinned; Docker image `mcr.microsoft.com/playwright/python:v1.63.0-noble`.
- Every run writes `VERSIONS.json` (chromium, playwright, axe, model sha, protocol sha, git sha).
- Web: shadcn components in `apps/web/src/components/ui` are owned source; add with `pnpm dlx shadcn@latest add <name>`. Never `-b radix`.
- Web must pass its own eight checks: `@axe-core/playwright` zero violations on every route is a CI gate.
- Record every design decision in `DECISIONS.md` (ADR: context, options, decision, evidence, date) and every rejected approach in `FAILED_ATTEMPTS.md`. Append progress to `NOTES.md`.
- Commit small. One milestone = one branch `m<N>-<slug>`. Run `make check` before reporting done. Finish each milestone report with: tests run, numbers achieved, deviations from PLAN.

## Don't
- Don't add Celery, Redis, Postgres, Redux, Prisma, ESLint, Storybook, cmdk.
- Don't install torch/rfdetr outside the `ml` extra; ONNX via onnxruntime is the shipped inference path.
- Don't write under `data/` in tests; use `tmp_path`.
- Don't commit `*.png` > 200 KB, `*.onnx`, `*.pt`, `*.db`.
- Don't add new success criteria, thresholds or rule interpretations; Protocol v1.1 is fixed. If something is ambiguous, pick the Protocol v1.1 reading and write it in `NOTES.md`.
- Don't use toasts for validation errors, spinners over 300 ms, colour as the only severity signal, or drag-only controls.

## Env
`.env.example` is the contract (`BENCHMARK_DIR`, `TRUTH_PATH`, `DATA_DIR`, `PLAYWRIGHT_BROWSERS_PATH=0` in Docker). Never commit `.env`. This machine: MacBook Pro, Apple M5 Pro, 48 GB. Training runs here only (torch MPS, `PYTORCH_ENABLE_MPS_FALLBACK=1`); no CUDA path is needed. Never start the full training run before the M10 smoke gate passes. Shipped inference is ONNX on CPU.
