# wcag-auditor

ML-assisted accessibility auditor for web UI screenshots, aligned with WCAG 2.2. Final-year research artefact (L.W.S.D. Alwis, NIBM / Coventry University).

## Start here

Development follows the milestones in `PLAN.md` §10, one per branch.

Documents: `PLAN.md` (contract), `DESIGN_SPEC.md` (UI), `CHECK_CATALOGUE.md` (criteria), `DECISIONS.md` (ADRs), `NOTES.md`, `FAILED_ATTEMPTS.md`.

The frozen benchmark and ground truth live in `../04_Data_Collection/` and are never modified from here.
