# wcag-auditor

ML-assisted accessibility auditor for web UI screenshots, aligned with WCAG 2.2. Final-year research artefact (L.W.S.D. Alwis, NIBM / Coventry University).

## Start here

1. `bash setup.sh` copies the plan documents in, initialises git and opens VS Code.
2. Open a terminal in this folder and run `claude`.
3. Paste the **M0** prompt from `MILESTONES.md`. One milestone per session, on its own branch.

Documents: `PLAN.md` (contract), `CLAUDE.md` (rules for Claude Code), `MILESTONES.md` (task prompts), `DESIGN_SPEC.md` (UI), `CHECK_CATALOGUE.md` (criteria), `DECISIONS.md` (ADRs), `NOTES.md`, `FAILED_ATTEMPTS.md`.

The frozen benchmark and ground truth live in `../04_Data_Collection/` and are never modified from here.
